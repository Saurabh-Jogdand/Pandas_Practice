# Pandas Practice Repository

This repository contains structured practice notebooks for learning and implementing core concepts of the Pandas library in Python. The notebooks are organized topic-wise and cover data manipulation, preprocessing, and analysis techniques commonly used in data science workflows.

## Objective

The purpose of this repository is to build a strong foundation in Pandas by practicing essential operations on structured datasets using Jupyter Notebooks.

## Contents

### 1. Series (1)Series.ipynb
- Introduction to Pandas Series
- Creating Series from lists, NumPy arrays, and dictionaries
- Indexing, slicing, and basic operations

### 2. DataFrames (2)DataFrames.ipynb
- Creating DataFrames
- Row and column selection
- Data inspection and basic transformations

### 3. Missing Data (3)MissingData.ipynb
- Identifying missing values
- Handling null values using dropna() and fillna()
- Data cleaning techniques

### 4. Merging, Joining, Concatenation (4)MergingJoiningConcatenation.ipynb
- Combining datasets using merge()
- Joining DataFrames
- Concatenation of multiple datasets

### 5. GroupBy and Aggregation (5)GroupByAggregation.ipynb
- Grouping data using groupby()
- Applying aggregate functions
- Summarizing data

### 6. Pivot Tables (6)PivotTables.ipynb
- Creating pivot tables
- Data summarization and restructuring
- Multi-level indexing

### 7. Operations (7)Operations.ipynb
- Element-wise operations
- Applying functions
- Data transformations

### 8. Feature Extraction (FeatureExtraction.ipynb)
- Extracting meaningful features from raw data
- Preparing data for analysis and modeling

### 9. Datasets
- Countries.csv
- anime.csv

These datasets are used for practicing real-world data manipulation and analysis.

## Tools and Technologies

- Python

## Learning Outcomes

- Understanding of structured data handling using Pandas

- Performing data transformations and aggregations
